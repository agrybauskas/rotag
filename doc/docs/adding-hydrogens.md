One important factor when calculating side-chain rotations is hydrogens.
Sometimes they are missing in the structural data.
It could be added with the ```-H``` option in ```rotag_add``` script.

```bash
rotag_add -H -c -s 4dhw-rotag-select.cif > 4dhw-rotag-select-H.cif
```
